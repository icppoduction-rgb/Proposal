# Отчёт: исправление `filter-host-path-file.json` (пути к файлам)

## Краткое описание проблемы
В `filter-host-path-file.json` сохранялись пути к корням датасетов (папкам), а не к конкретным файлам.  
Это нарушало контракт этапа фильтрации, где ожидаются именно файловые пути.

## Причина
В обработчике `HostDatasetFilterHandler` после прохождения фильтра добавлялся `dataset_root`, а не исходный `raw_path` файла.

## Что изменено
- Файл: `scripts/handlers/filter_host_dataset_handler.py`
  - В `filter_and_save()` заменено накопление путей:
    - было: добавление корня датасета;
    - стало: добавление полного пути к файлу (`raw_path`).
  - Удалена больше не нужная логика извлечения корня датасета (`_extract_dataset_root`).
  - Поле результата переименовано:
    - `dataset_paths_by_role` → `file_paths_by_role`.

## Что проверено
1. Запуск команды:
   - `python manage.py host dataset filter`
2. Проверка содержимого:
   - `temp_data/filter-host-path-file.json`
3. Результат:
   - в JSON по ролям записаны файловые пути (например, `...UAD-Adduser-10-1371.txt`), а не пути к папкам датасетов.

## Текущее состояние после фикса
- `filter-host-path-file.json` содержит пути к файлам.
- `filter-host-file.json` продолжает содержать имена файлов.
- Лог исключений сохраняется в `logs/filter.log`.
