# Датасет → Карта извлечения признаков

Этот документ сопоставляет каждый датасет с конкретными признаками, которые необходимо извлечь для обучения, валидации и тестирования модели.

---

## DNS-ветка

### CIC-Bell-DNS-EXF-2021

- **Роль:** Обучение
- **Стадия атаки:** Эксфильтрация

| Категория | Признаки |
|---|---|
| Статистические | Длина запроса, длина поддомена, количество уникальных поддоменов, соотношение уникальных поддоменов к общему числу |
| Энтропия | Энтропия Шеннона символов доменного имени, энтропия строки запроса |
| Временные | Частота запросов на домен, интервалы между запросами, количество запросов за временное окно (вход для LSTM) |
| Протокольные | Размер ответа, распределение TTL, распределение типов запросов (TXT/MX/CNAME) |
| Специфичные для датасета | Stateful-признаки (уровень соединения), stateless-признаки (уровень запроса) |

---

### CIC-Bell-DNS-2021

- **Роль:** Обучение + Валидация
- **Стадия атаки:** Эксфильтрация

|---|---|

## Host-ветка — Датасеты системных вызовов

### ADFA IDS

- **Роль:** Обучение
- **Стадия атаки:** Подготовка данных / Сбор

| Категория | Признаки |
|---|---|
| Частотные | Частотное распределение системных вызовов на трассу (количество каждого уникального syscall ID) |
| N-граммы | Частоты биграмм и триграмм последовательностей системных вызовов |
| Переходы | Вероятности перехода между системными вызовами (вход для LSTM) |
| Сложность | Количество уникальных системных вызовов на трассу, длина трассы |
| Последовательности | Упорядоченные ID системных вызовов (прямой вход для LSTM) |

---

### LID-DS 2021

- **Роль:** Обучение
- **Стадия атаки:** Подготовка данных / Сбор

| Категория | Признаки |
|---|---|
| Syscall-признаки | Те же, что и для ADFA IDS |
| Параметры | Значения аргументов системных вызовов (при наличии) |
| Временные | Интервалы между системными вызовами, частота syscall за временное окно |
| Назначение | Основной датасет для LSTM-моделирования последовательностей поведения процессов |

---

### LID-DS 2019

- **Роль:** Валидация
- **Стадия атаки:** Подготовка данных / Сбор

| Категория | Признаки |
|---|---|
| Признаки | Тот же набор признаков, что и LID-DS 2021 |
| Назначение | Кросс-версионная валидация, CVE-сценарии атак, проверка переобучения |

## Host-ветка — Аутентификация и корпоративные логи

### LANL Dataset

- **Роль:** Валидация
- **Стадия атаки:** Латеральное перемещение / Повышение привилегий

| Категория | Признаки |
|---|---|
| Паттерны аутентификации | Частота пар источник-назначение хостов, соотношение успешных/неуспешных аутентификаций на пользователя |
| Временные | Распределение входов по времени суток и дням недели, длительность сессий |
| Поведенческие | Частота взаимодействия пользователь-хост, новые пары хостов |
| Аномалии | Отклонение от базовых паттернов доступа пользователя |

---

### Windows Event Log / OTRF Security Datasets

- **Роль:** Валидация
- **Стадия атаки:** Разведка, Латеральное перемещение

| Категория | Признаки |
|---|---|
| Event ID | Частота событий 4624/4625 (вход в систему), 4672 (привилегии), Sysmon Event 1 (создание процесса) |
| Цепочки процессов | Глубина дерева родительский-дочерний процесс, нетипичные пары родитель-потомок |
| Командная строка | Энтропия строки аргументов (обнаружение обфускации) |
| Временные | Частота событий на хост, паттерны последовательностей событий |

---

### Maintainable Log Dataset

- **Роль:** Обучение
- **Стадия атаки:** Разведка, Подготовка данных

| Категория | Признаки |
|---|---|
| Паттерны логов | Паттерны последовательностей событий по 20 типам логов |
| Объём | Объём логов на хост во времени (обнаружение всплесков) |
| Многоэтапные | Корреляции событий между типами логов для отслеживания прогрессии атаки |
| Временные | Частота событий в логах, интервалы между событиями (вход для LSTM) |

## Host-ветка — Тестовые датасеты

### Dynamic Malware Analysis Dataset

- **Роль:** Тестирование
- **Стадия атаки:** Подготовка данных, Эксфильтрация

| Категория | Признаки |
|---|---|
| Ядерные вызовы | Частотные распределения вызовов ядра |
| Активность пользователя | Паттерны активности пользовательского уровня при выполнении вредоносного ПО |
| Назначение | Поведение, связанное с вредоносным ПО, активность хоста перед эксфильтрацией |

---

### ISOT Cloud IDS Dataset

- **Роль:** Тестирование
- **Стадия атаки:** Подготовка данных

| Категория | Признаки |
|---|---|
| Syscall | Те же syscall-признаки, что и для ADFA/LID-DS (при наличии) |
| Облачные метрики | Аномалии CPU/памяти/IO |
| Логи | Паттерны системных логов в облачных нагрузках |
| Назначение | Проверка переносимости на облачную среду |

---

### Unified Host-Network Dataset (LANL)

- **Роль:** Тестирование
- **Стадия атаки:** Разведка, Латеральное перемещение, Подготовка данных, Эксфильтрация

| Категория | Признаки |
|---|---|
| Хост | Логи аутентификации, события процессов (те же признаки, что и LANL) |
| Сеть | Длительность потока, байты, пакеты, протокол, состояние соединения |
| Фьюжн | Связанные хост+сетевые признаки из одной среды |
| Назначение | Валидация архитектуры многоисточниковой интеграции на реально связанных данных |
