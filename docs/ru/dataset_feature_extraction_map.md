# Карта соответствия наборов данных и извлекаемых признаков (обновлённая)

Данный документ описывает, какие признаки необходимо извлекать из каждого набора данных для обучения, валидации и тестирования моделей. Карта построена таким образом, чтобы покрыть весь жизненный цикл эксфильтрации данных:

1. Разведка (Reconnaissance)
2. Повышение привилегий (Privilege Escalation)
3. Боковое перемещение (Lateral Movement)
4. Сбор данных (Collection)
5. Подготовка данных (Data Staging)
6. Эксфильтрация (Exfiltration)

---

# Покрытие жизненного цикла эксфильтрации данных

| Этап | Поддерживающие наборы данных |
|---|---|
| Разведка | OTRF, Maintainable Log Dataset, Unified Host-Network |
| Повышение привилегий | OTRF, LANL, Unified Host-Network |
| Боковое перемещение | LANL, OTRF, Unified Host-Network |
| Сбор данных | ADFA IDS, LID-DS 2021, LID-DS 2019, Dynamic Malware Analysis, Maintainable Log Dataset, Unified Host-Network |
| Подготовка данных | ADFA IDS, LID-DS 2021, LID-DS 2019, Maintainable Log Dataset, Dynamic Malware Analysis, ISOT Cloud IDS, Unified Host-Network |
| Эксфильтрация | CIC-Bell-DNS-EXF-2021, CIC-Bell-DNS-2021, Mendeley DNS Dataset, Unified Host-Network |

# Ветвь DNS

## CIC-Bell-DNS-EXF-2021

- Роль: Обучение
- Этап атаки: Эксфильтрация

| Категория | Признаки |
|---|---|
| Статистические | Длина запроса, длина поддомена, количество уникальных поддоменов, отношение уникальных поддоменов к общему числу |
| Энтропия | Энтропия Шеннона для символов домена, энтропия строки запроса |
| Временные | Частота запросов к домену, интервалы между запросами, количество запросов в окне времени (вход для LSTM) |
| Протокольные | Размер ответа, распределение TTL, распределение типов запросов |
| Специфические | Stateful и stateless DNS-признаки |

## CIC-Bell-DNS-2021

- Роль: Обучение + Валидация
- Этап атаки: Эксфильтрация

| Категория | Признаки |
|---|---|
| Признаки | Тот же набор признаков, что и в EXF-2021 |
| Назначение | Базовая модель нормального DNS-трафика и контроль ложных срабатываний |

## Mendeley DNS Exfiltration Dataset

- Роль: Тестирование
- Этап атаки: Эксфильтрация

| Категория | Признаки |
|---|---|

# Ветвь хостовых данных — наборы системных вызовов

## ADFA IDS

- Роль: Обучение
- Этап атаки: Сбор данных, Подготовка данных

| Категория | Признаки |
|---|---|
| Частотные | Распределение частот системных вызовов |
| N-граммы | Частоты биграмм и триграмм |
| Переходы | Вероятности переходов между системными вызовами |
| Сложность | Количество уникальных системных вызовов, длина трассы |
| Индикаторы сбора | Частота open(), read(), access(), stat(), readdir() |
| Индикаторы сбора | Перечисление файлов, обход директорий |
| Последовательности | Исходные последовательности системных вызовов для LSTM |

## LID-DS 2021

- Роль: Обучение
- Этап атаки: Сбор данных, Подготовка данных, Подготовка к эксфильтрации

| Категория | Признаки |
|---|---|
| Системные вызовы | Аналогично ADFA IDS |
| Параметры | Аргументы системных вызовов |
| Временные | Интервалы между вызовами |
| Сбор данных | Частота доступа к файлам, перечисление файлов |
| Поведенческие | Подозрительные цепочки выполнения процессов |

## LID-DS 2019

- Роль: Валидация
- Этап атаки: Сбор данных, Подготовка данных

| Категория | Признаки |
|---|---|
| Признаки | Тот же набор признаков, что и в LID-DS 2021 |
| Назначение | Межверсийная валидация |

# Ветвь хостовых данных — журналы аутентификации и корпоративные журналы

## LANL Dataset

- Роль: Валидация
- Этап атаки: Повышение привилегий, Боковое перемещение

| Категория | Признаки |
|---|---|
| Аутентификация | Частота пар источник-назначение, отношение успешных и неуспешных входов |
| Временные | Распределение входов по времени суток, длительность сессий |
| Поведенческие | Частота взаимодействий пользователь-хост |
| Повышение привилегий | Использование привилегированных учётных записей, доля входов администратора |
| Аномалии | Необычное использование учётных записей, отклонение от базового поведения |

## Windows Event Log / OTRF

- Роль: Валидация
- Этап атаки: Разведка, Повышение привилегий, Боковое перемещение

| Категория | Признаки |
|---|---|
| Идентификаторы событий | 4624, 4625, 4672, Sysmon Event 1 |
| Цепочки процессов | Связи родительских и дочерних процессов |
| Повышение привилегий | Выполнение процессов с повышенными правами |
| PowerShell | Выполнение закодированных команд |
| Разведка | События обнаружения учётных записей и системы |
| Командная строка | Энтропия аргументов |
| Временные | Частота событий и последовательности событий |

## Maintainable Log Dataset

- Роль: Обучение
- Этап атаки: Разведка, Сбор данных, Подготовка данных

| Категория | Признаки |
|---|---|
| Шаблоны журналов | Последовательности событий |
| Объём | Всплески объёма журналов |
| Сбор данных | Частота событий доступа к файлам |
| Многоэтапные признаки | Корреляции между различными типами журналов |
| Временные | Частота событий и интервалы между ними |

# Тестовые наборы данных

## Dynamic Malware Analysis Dataset

- Роль: Тестирование
- Этап атаки: Сбор данных, Подготовка данных, Подготовка к эксфильтрации

| Категория | Признаки |
|---|---|
| Ядро ОС | Распределение вызовов ядра |
| Сбор данных | Доступ к файлам и обнаружение файлов |
| Поведение процессов | Цепочки запуска вредоносных процессов |
| Активность пользователя | Поведенческие шаблоны пользователя |

## ISOT Cloud IDS Dataset

- Роль: Тестирование
- Этап атаки: Подготовка данных

| Категория | Признаки |
|---|---|
| Системные вызовы | Аналогично ADFA/LID-DS |
| Облачные метрики | Аномалии CPU, памяти и ввода-вывода |
| Журналы | Шаблоны журналов облачных нагрузок |

## Unified Host-Network Dataset (LANL)

- Роль: Тестирование
- Этап атаки: Разведка, Повышение привилегий, Боковое перемещение, Сбор данных, Подготовка данных, Эксфильтрация

| Категория | Признаки |
|---|---|
| Хост | Журналы аутентификации, события процессов |
| Повышение привилегий | Признаки, связанные с привилегиями |
| Сбор данных | Признаки доступа к файлам |
| Сеть | Длительность потока, байты, пакеты, протокол, состояние соединения |
| Интеграция | Коррелированные признаки хоста и сети |
| Назначение | Сквозная проверка архитектуры мультиисточниковой интеграции |
