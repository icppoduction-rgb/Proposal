---------------------------------

registry/parser/scanner состояние.


4. Универсальный шаблон нормализации одного формата
--------------------------------------------------

Dry-run:

python manage.py stage-two mark-ready --branch <dns|host> --role <TRAIN|VALIDATION|TEST|EXPERIMENTS> --format <FORMAT> --dry-run

Apply:

python manage.py stage-two mark-ready --branch <dns|host> --role <TRAIN|VALIDATION|TEST|EXPERIMENTS> --format <FORMAT> --apply

Normalize:

python manage.py stage-two normalize-format --branch <dns|host> --role <TRAIN|VALIDATION|TEST|EXPERIMENTS> --format <FORMAT> --limit 100

Fallback syntax:

python manage.py stage-two mark-ready dry-run:host:TRAIN:auth.log
python manage.py stage-two mark-ready apply:host:TRAIN:auth.log
python manage.py stage-two normalize-format host:TRAIN:auth.log:100

Правильная последовательность для каждого формата:

1. parser-coverage
2. mark-ready --dry-run
3. mark-ready --apply
4. normalize-format
5. run-duckdb-checks / run-leakage-checks / readiness_check
