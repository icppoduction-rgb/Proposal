# JSON Helper: `scripts.handlers.json_handler`

## Purpose

`JsonDataManager` is the shared helper for reading and writing Stage One JSON files. It is used by handlers in `analyze_dataset`, `filter_dataset`, `sort`, `save_sort`, `dns_analyze`, and `host_analyze`.

## Components

| File | Purpose |
|---|---|
| `scripts/handlers/json_handler/json_data.py` | Actual `JsonDataManager` implementation. |
| `scripts/handlers/json_handler/json-data.py` | Thin compatibility wrapper/import for the legacy file name. |

## API

| Method | Input | Output | Behavior |
|---|---|---|---|
| `read(default=None)` | Constructor path | Python object loaded from JSON or `default` | Returns `default` when the file does not exist. |
| `write(data)` | JSON-serializable object | `None` | Creates parent directory and writes UTF-8 JSON. |

## Pipeline Position

`JsonDataManager` contains no business logic. It only provides a shared way to work with temporary JSON artifacts in `PATH_TEMP_DATA` and summary/report JSON generated by content-analysis handlers.

## Constraints

- The helper does not validate JSON Schema. Structure validation is done by specific handlers.
- Invalid JSON errors are not hidden and propagate to the caller.
